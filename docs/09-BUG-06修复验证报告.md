## 二、改动清单

全部集中在 `sentiment/segment.py`，共 4 处。

| # | 位置 | 改动 | 作用 |
|---|---|---|---|
| **A** | `_DISCLAIMER` 词表 | 补 11 个**独立**声明特征词（风险自担 / 自行承担 / 仅供参考 / 请投资者 / 不保证…准确 等） | 原先只收「据此操作，风险自担」这类完整搭配，拆开写就漏 |
| **B** | 续写分支 `segment.py:626` | 覆盖 advice 前加声明语校验，命中则不覆盖 | **核心结构性防线**，直接修掉 BUG-06 |
| **C** | `_extract_advice` | 候选建议**按句剔除**声明句；退化路径同样跳过声明句 | 块内无标题声明的同类防线 |
| **D** | 新增 `_looks_like_disclaimer_advice` / `_drop_disclaimer_sentences` | 声明语判定与按句剔除 | B、C 共用 |

### 核心改动（B）

```python
elif last_group and last_group[0].product is not None:
    cont_advice = _extract_advice(body) if _STRONG_LABEL.search(body) else ''
    # ★ BUG-06：文末【风险提示】里的「操作建议：据此操作风险自担」
    #   会把上一个品种的真实方向整个盖掉（逢低偏多 → 逢高沽空，符号翻转）。
    #   这里只拦 advice 覆盖，raw_text 照常拼接——
    #   下钻看原文时该机构说过的话一句不少，但方向不被法律文本污染。
    if _looks_like_disclaimer_advice(cont_advice):
        cont_advice = ''
```

### 两个刻意的设计取舍

1. **没有把「风险提示」加进 `_DISCLAIMER_START` 白名单。**
   那个函数是从匹配位置**砍掉后面全部内容**。真实研报里 `【风险提示】` 常作为每个品种的
   分析小节出现在中部，从那里砍下去会把后面所有品种的观点全删光。用例 F05 守这条。

2. **声明语词表刻意不收「谨慎 / 风险 / 注意」。**
   它们在真实建议里极常见（「谨慎逢低偏多」「注意回调风险」）。
   判定失败的代价不对称：漏杀只是少覆盖一次，误杀会丢掉真实方向，所以**宁窄勿宽**。
   用例 F09/F10/F11 守这条。

## 四、红转绿证明

把仓库复制到 `/tmp` 并**回退全部改动**，跑同一套验收用例：

```
AssertionError: '逢低偏多' not found in '请投资者谨慎决策，逢高沽空需自担风险。'
FAIL: test_F03_无标题声明段不得劫持方向
AssertionError: '沽空' not found in '以上建议仅供参考，投资者应自行承担风险。'

Ran 19 tests in 0.017s
FAILED (failures=2)
```

**19 条里只有 2 条（F01、F03）在修复前是红的**——这一点需要如实说明。

### 为什么只有 2 条红：一个意外发现

排查发现 `MIN_MACRO_LEN = 30` 在无意中挡住了**短**声明块：

```
块正文 '操作建议：本报告仅供参考，据此操作风险自担。' = 22 字 < 30 字
→ 被当成「栏目名/页码碎片」直接 continue 丢弃，根本没进续写分支
```

所以 F02（重要提示，22 字）、F07（连续声明块）在修复前就是绿的——**靠的是一条为别的
目的设的长度闸门，不是真正的防御**。F01 的声明块有两行、超过 30 字，才触发了缺陷。

这意味着：

> **缺陷的触发条件是「声明块 ≥ 30 字」——而真实研报的免责声明都是长段落，必然触发。**

样本之所以没暴露，是因为样本的声明段恰好被 `_DISCLAIMER_START` 白名单吃掉了。

F02/F07 虽然修复前就绿，仍然保留：它们锁住的是「短声明块也不许劫持」这个行为，
防止将来有人调整 `MIN_MACRO_LEN` 时悄悄打开这个口子。

## 五、过程中引入并修掉的一个回归（如实记录）

改动 C 的**第一版**写成了「候选建议整段命中声明语就整段拒绝」，结果打破了一条存量测试：

```
FAIL: test_免责声明里的不构成投资建议不算标签
AssertionError: '逢低偏多' not found in '本报告不构成投资建议。'
```

**根因**：`_first_sentence_after` 在原文没有换行时会带出**若干句**，
`'操作建议：逢低偏多。本报告不构成投资建议。'` 整个作为一个候选。
整段判声明，就把真实建议「逢低偏多」连同法律文本一起丢掉，反而退化到更差的结果。

**修正**：改成**按句剔除**（`_drop_disclaimer_sentences`），剔干净后为空才拒绝。

| 输入 | 修复前 | 第一版（错） | 最终 |
|---|---|---|---|
| `操作建议：逢低偏多。本报告不构成投资建议。` | `'逢低偏多。本报告不构成投资建议。'` | `'本报告不构成投资建议。'` ❌ | `'逢低偏多。'` ✅ |

**最终结果比修复前更准**——原先 advice 里还拖着一句法律文本，现在干净了。

> 这次回归是**存量测试发挥作用的一次实证**：181 条里有一条正好守住了这个行为。
> 也侧面说明 07 报告里「测试和实现共享同一套假设」的批评不是全盘否定——
> 存量测试对**已知**行为的锁定是有效的，它弱的是**对抗性**覆盖。

## 七、顺带修复：BUG-13

`scripts/run-tests-docker.sh` 的幂等检查原先只**打印**不**断言**：

```bash
python run.py ingest ... | grep -oE "新增 [0-9]+ 篇..." || true   # ← 永不失败
```

改为真断言：

```bash
echo "$out" | grep -q "新增 0 篇" || { echo "  ✗ Python ${v} 幂等未通过"; fail=1; }
```

**负向验证**：把断言值改成不可能满足的「新增 999 篇」，脚本如期输出 `存在失败 ✗`，
证明这条断言真的会拦人，不是又一个摆设。
