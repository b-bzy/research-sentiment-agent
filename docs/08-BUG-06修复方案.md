# BUG-06 修复方案：免责声明劫持品种方向

> 缺陷来源：[07-测试报告.md](07-测试报告.md) BUG-06（P0，建议修复顺序第 1 位）
> 影响文件：`sentiment/segment.py`
> 本文含：根因分析 → 修复设计 → 验收测试用例

---

## 一、缺陷复述

文末 `【风险提示】` 小节里的「操作建议：」会**覆盖上一个品种的真实操作建议**。

```python
from sentiment.segment import split_segments
t = """【黑色】螺纹钢
逻辑分析：需求回暖。
操作建议：逢低偏多。

【风险提示】
本报告基于公开资料，不保证准确性。
操作建议：请投资者谨慎决策，逢高沽空需自担风险。
"""
split_segments(2, t)
# → 1 块：product=RB, advice='请投资者谨慎决策，逢高沽空需自担风险。'
```

螺纹钢的真实方向 `逢低偏多 (+1.0)` 被免责声明的 `逢高沽空 (−1.0)` 取代，**符号翻转**。

**为什么必须修**：几乎所有券商研报都带免责声明或风险提示，这条在真实数据上是必踩。

---

## 二、根因分析（三层，逐层实证）

### 现有防线与它的缺口

代码本身**已有**免责声明防御，且对 `【免责声明】` 有效：

```python
_strip_disclaimer_tail('...【免责声明】...')   # ✓ 砍掉尾巴，advice 正确
_strip_disclaimer_tail('...【风险提示】...')   # ✗ 原样返回
```

失效链路有三个环节，缺一不可：

| 层 | 机制 | 实测结果 |
|---|---|---|
| **L1** | `_DISCLAIMER` 词表判定该块是不是声明块 | `_is_disclaimer('【风险提示】本报告基于公开资料，不保证准确性。')` → **False** |
| **L2** | 无品种块的归属判定：宏观块 or 上一品种的续写 | `_is_macro_title('风险提示')` → **False** ⇒ 落入**续写**分支 |
| **L3** | 续写分支的覆盖逻辑（`segment.py:626-629`） | `if _STRONG_LABEL.search(body)` 命中即**无条件覆盖** advice |

```python
# sentiment/segment.py:626-629  ← 问题代码
elif last_group and last_group[0].product is not None:
    cont_advice = _extract_advice(body) if _STRONG_LABEL.search(body) else ''
    for draft in last_group:
        draft.raw_text = f'{draft.raw_text}\n{body}'
        if cont_advice:           # 续写里带显式「操作建议：」才覆盖
            draft.advice = cont_advice
```

L3 是要害：**它只检查「有没有操作建议标签」，从不检查「这条建议像不像人话」。**

### 一个重要的反直觉发现

`【风险提示】` **会**正常生成块头，所以它出现在**文档中部**时一切正常：

```python
# 【黑色】螺纹钢 → 【风险提示】 → 【有色】沪铜 → 【能化】甲醇
# → RB='逢低偏多。'  CU='逢高沽空。'  MA='区间操作。'   全部正确
```

**只有当声明块是最后一块时才出事**——因为后面没有新的品种块把 `last_group` 顶掉。
这解释了为什么 27 篇样本没触发：样本的声明段都被 `_DISCLAIMER_START` 白名单吃掉了。

## 三、修复设计

### 设计原则：不做打地鼠

最容易想到的修法是「把 `风险提示` 加进 `_DISCLAIMER_START` 白名单」。**这个修法是错的**，两个理由：

1. **会误删正文。** `_strip_disclaimer_tail` 是从匹配位置**砍掉后面全部内容**。
   真实研报里 `【风险提示】` 常作为**每个品种的分析小节**出现在中部
   （「风险提示：需求不及预期」），从那里砍下去会把后面所有品种的观点全部删光。
2. **词表永远补不完。** 风险提示 / 重要提示 / 特别提示 / 风险揭示 / 投资者须知 /
   郑重声明 / 重要申明……而且大量免责声明**根本没有标题**。

所以真正的修复要落在 **L3 的结构性校验**上：**内容判定优先于标题判定。**

### 三处改动

#### 改动 A（L1，扩词表）——让明显的声明块直接被丢弃

`_DISCLAIMER` 目前只收「据此操作，风险自担」这类**完整搭配**，拆开写就漏。补充**独立**特征词：

```python
_DISCLAIMER = re.compile(
    r'免责声明|分析师声明|版权所有|不构成投资建议|据此操作，风险自担|'
    r'投资咨询业务资格|证监许可|期货从业资格|本报告的著作权|联系我们|客服电话|'
    # ↓ 新增：声明语的独立特征词（拆开写、换语序也能命中）
    r'风险自担|风险自负|自行承担|概不负责|不承担任何|不保证.{0,6}(准确|完整|可靠)|'
    r'仅供参考|据此入市|请投资者|投资者应当|风险提示如下'
)
```

#### 改动 B（L3，结构性防线）——续写不得用声明语覆盖真实建议 ★核心

新增一个「这句话是不是声明语」的判定，**续写覆盖前必须过这一关**：

```python
#: 声明语特征：这些短语在真实操作建议里几乎不可能出现，
#: 一旦出现在候选 advice 里，说明抽到的是法律文本而不是观点。
#: ★ 刻意不收「谨慎」「风险」「注意」——它们在真实建议里极常见
#:   （「谨慎逢低偏多」「注意回调风险」），收进来会误杀。
_ADVICE_DISCLAIMER = re.compile(
    r'风险自担|风险自负|自行承担|自担风险|概不负责|不承担|不保证|不构成|'
    r'仅供参考|据此操作|据此入市|请投资者|投资者应|谨慎决策|市场有风险|入市需谨慎'
)


def _looks_like_disclaimer_advice(advice: str) -> bool:
    """候选操作建议是不是法律声明语。

    ★ 这是本项目「方向判反」这一类缺陷的**结构性防线**：
      标题白名单永远补不完，但声明语的措辞高度固定。
      判定失败的代价是不对称的——漏杀只是少覆盖一次，误杀会丢掉真实观点，
      所以词表宁窄勿宽。
    """
    return bool(advice) and bool(_ADVICE_DISCLAIMER.search(advice))
```

续写分支改为：

```python
elif last_group and last_group[0].product is not None:
    cont_advice = _extract_advice(body) if _STRONG_LABEL.search(body) else ''
    # ★ BUG-06：声明块的「操作建议：据此操作风险自担」不得覆盖真实观点。
    #   raw_text 仍然拼进去（下钻时原文一句不少），只是不改方向。
    if _looks_like_disclaimer_advice(cont_advice):
        cont_advice = ''
    for draft in last_group:
        draft.raw_text = f'{draft.raw_text}\n{body}'
        if cont_advice:
            draft.advice = cont_advice
```

**关键取舍**：`raw_text` 照常拼接、只拦 `advice` 覆盖。
这样下钻看原文时该机构说过的话一句不少，但方向不被污染。

#### 改动 C（同类防线下沉到 `_extract_advice`）

块**内部**也可能出现同样的问题（正文末尾直接跟一段无标题声明）。
`_extract_advice` 取「最靠后的强标签」，同样需要跳过声明语：

```python
for pattern in (_STRONG_LABEL, _WEAK_LABEL):
    matches = list(pattern.finditer(text))
    # ★ 从后往前找第一个「不像声明语」的候选（BUG-06 同类防线）
    for match in reversed(matches):
        advice = _first_sentence_after(text, match.end())
        if advice and not _looks_like_disclaimer_advice(advice):
            return advice
```

原逻辑只看 `matches[-1]`，现在退化为逐个回退，行为在无声明语时**完全一致**。

### 风险评估

| 风险 | 评估 | 缓解 |
|---|---|---|
| 误杀真实建议 | 词表刻意不含「谨慎/风险/注意」这类高频词 | 用例 F09–F11 专门防守 |
| 改变现有 227 块结果 | 样本无 `【风险提示】`，声明段已被白名单处理 | 用例 F13/F14 逐值锁定 |
| `_extract_advice` 回退改变既有行为 | 无声明语时与原逻辑等价 | 181 个存量单测全绿即可证明 |
| 中部声明块砍掉正文 | **本方案不动 `_strip_disclaimer_tail`**，从设计上排除 | 用例 F05 |
