# 同类产品功能调研：研报观点的多空量化

> 采集时间：2026-09-10 ｜ 数据源：各产品官网 / 官方文档 / 白皮书 / 券商研报
> 只调研公开可查的产品功能与打分口径，不涉及任何非公开信息

---

## 〇、调研口径

**本项目要实现的唯一功能：** 把各家期货公司的研报判成看多/看空/中性，汇总成「全市场当前偏多还是偏空」，且按时间可比。

因此本次只看**做同一件事**的产品，回答三个问题：

1. 成熟产品怎么定义「多空分数」？
2. 多篇怎么汇总成一个市场结论？
3. 结论怎么交付给用户？

**明确排除**：量价类情绪指数（CNN Fear & Greed 等，情绪来自行情不来自文本）、调查/持仓类情绪（AAII、COT）、多 Agent 交易决策平台。它们跟「研报判多空」不是同一件事。

---

## 一、最直接的四个对标

### 1.1 曲合网等期货资讯站的「研报观点汇总表」—— 本项目的人工版对手

每日人工整理全市场期货研报，形成：

| 品种 | 期货公司 | 操作建议 | 本周趋势 |
|---|---|---|---|
| 沪金 | 长安期货 | 暂不看空 | 震荡 |
| 沪铜 | | 谨慎逢低偏多 | 多头 |
| 螺纹钢 | | 逢低偏多思路为主 | 震荡 |
| 焦煤 | | 前多保护利润 | 多头 |
| PVC | | 观望为主 | 偏多 |

**这是全篇调研里最有价值的一个发现**，三个原因：

1. **需求已被人工满足，说明产品假设成立。** 市场自发出现了「多机构 × 多品种 × 多空判断」的汇总形态。
2. **它缺的三样，正好是本项目的价值：**
   - 只有横截面，**没有时间序列** —— 今天的表和上周的表没法比，看不出情绪在升温还是降温
   - 只有定性标签，**没有量化分数** —— 「谨慎逢低偏多」没法加总成一个数
   - 只有品种粒度，**没有大盘口径** —— 看不出全市场整体偏多还是偏空
3. **它提供了现成的标签体系和难例样本。** 「操作建议 + 趋势判断」两栏就是研报观点结构化的天然字段；而「暂不看空」「谨慎追空」「前多保护利润」这类含糊表达，正是打分模型最该重点采样的标注难例。

### 1.2 LSEG MarketPsych 的 `longVsShort` —— 口径上最直接的对标

MarketPsych 实时解析全球媒体，输出数值指标序列。其中两个指标跟本项目完全同构：

| 指标 | 官方定义 | 区间 |
|---|---|---|
| **longVsShort** | **买入的引用数，减去做空或卖出的引用数** | −1 ~ 1 |
| **longShortForecast** | 买入预测，减去做空预测 | −1 ~ 1 |

覆盖标的包含**商品与能源（C&E）**，且该类标的的配套指标是 `priceDirection`、`priceForecast`、`supplyVsDemand`、`productionVolume`——**这几乎就是期货研报观点的标准结构化字段**，本项目的关键词提取维度可以直接对齐：价格方向、价格预测、供需、库存产量。

**另外两个必须借鉴的设计：**

- **Buzz 与 Sentiment 分离。** Buzz 衡量"讨论了多少"，Sentiment 衡量"往哪个方向"。→ 本项目应把「今天有多少家发了研报」和「这些研报偏多还是偏空」拆成两个数，**前者作为后者的置信度权重**。3 家看多和 30 家看多不该同权。
- **NA ≠ 0。** 官方文档专门强调：真 0 意味着"有正有负、净额为零"，NA 意味着"根本没有相关文本"，两者含义相反。→ 某品种当日无研报覆盖时不能记 0（会被误读为中性观点），应记缺失。

### 1.3 RavenPack / Bigdata.com —— 分数形态的设计参考

| 设计点 | 做法 | 对本项目的意义 |
|---|---|---|
| 分数区间 | **−1.00 ~ +1.00** 连续值，同时含方向和强度 | 单一数轴，天然可聚合、可比较 |
| 模型形态 | 从回归改为**分类**：把 [−1,1] 切成 **41 个 bin**，输出每个 bin 的概率，从而得到**置信度** | ⭐ 分类比回归稳，且天然产出置信度——低置信度样本可在汇总时降权或送人工复核 |
| 打分粒度 | **chunk（文本块）级**而非整篇 | 与研报"一篇多品种多观点"的结构匹配 |
| 官方承认的局限 | 不区分观点视角，一段内有对立观点会被打成中性或被主导观点吞掉 | → 本项目必须先切分再打分 |

### 1.4 华泰《基于 BERT 的分析师研报情感因子》—— 国内方法论的最佳公开样本

这是国内公开可查的、与本项目做法最接近的研究。

**构建流程：** 预训练中文 BERT → 用 Wind 有情感标注的金融舆情文本微调 → 在无标注的研报摘要上预测情感 → 构建因子。

**聚合口径（本项目"设定统计区间"的直接对标）：**
- 情感得分 = 模型判为正面的概率 − 0.5，使中性文本约为 0
- 对每个**入库日**（非撰写日）取过去 **90 个自然日**的研报
- 篇内各句取均值 → 同标的当日多篇取均值 → 无研报记为空
- 对 90 天序列做**线性衰减加权求和**，越近权重越大
- 调整因子给**负面文本更大权重**，对冲研报正面偏斜

**因子检验的关键结论：** 原始情感因子表现最好，但对「研报评分因子」「研报数量因子」中性化后残差最差——说明信息大部分能被"多少家在写、给了什么评级"解释；只有做了负面加权的调整因子，残差才保持表现。

**三条硬约束：** ① 用入库时点，否则有未来函数 ② 聚合要时间衰减加权，不能简单平均 ③ 必须做中性化检验，证明相对"数家数"有增量。

## 二、交付形态参考（只看跟本项目相关的部分）

### 2.1 AlphaSense —— 研报智能化的交付标杆

覆盖 1700+ 研究机构的研报平台。跟本项目相关的三点：

- **每条答案都带原文片段引用。** ⭐ 金融场景的刚需——交易员不会接受一个没有出处的分数。**本项目的推送必须能下钻到「这个多空分由哪几篇研报的哪几句话构成」。**
- **Generative Grid**：对多篇文档同时套用多个 prompt，输出**表格形态**的结构化答案。跟本项目「多机构 × 多品种 → 多空矩阵」形态同构，可直接借鉴。
- **实时告警**：对任意关键词/列表设提醒，推送到邮箱或移动端。

其产品价值主张原文是「把静态的卖方 PDF 转成可行动的情报资产」——**它做检索问答，本项目做多空量化，是同一命题的两种答法。**

### 2.2 Wind / 同花顺 iFinD —— 国内基础设施

- **Wind**：国内近五十家研究机构的官方授权研报发布平台；Client API 可获取舆情与风险事件，**通过 AI 情感分析自动化运算**；智能应用 API 提供**研报拆解**能力。
  - 关键事实：**Wind 的情感标注语料是学界业界做中文金融情绪的通用基准**——华泰的研报情感因子就是用它微调 BERT 的。
- **同花顺 iFinD**：覆盖**期货（含期权）**；有「舆情与风控」模块和**「非结构化数据库」**（用算法把非结构化内容转成金融数据）。
  - 「非结构化数据库」是终端厂商对这类需求的产品化答案——**把研报里的观点抽成字段存起来**。本项目本质是它的垂直版：只做期货、只做多空维度，但做得更深，且直接产出可追踪的结论而非仅提供数据。

### 2.3 信息结构：一个数 + 可下钻的分项

CNN Fear & Greed Index 虽然是量价路线（不在本项目范围内），但它的**信息结构**值得照搬：**0–100 一个数 + 一个表盘 + 七个分项的下钻解释**。这类产品的成功不在算法复杂度，而在这个信息结构。

→ 本项目推送应遵循同样的三级结构：**大盘多空分 → 分品种/板块的多空构成 → 支撑它的研报原句**。

## 三、功能矩阵对比

| 维度 | 曲合网人工汇总 | MarketPsych | RavenPack | AlphaSense | **本项目** |
|---|---|---|---|---|---|
| 文本来源 | 期货公司研报 | 新闻+社媒 | 全球新闻 | 1700+ 研报源 | **多家期货公司研报** |
| 判断粒度 | 人工整篇 | 文本窗口 | chunk 级 | 文档级问答 | **观点级（按品种/周期切分）** |
| 分数形态 | 定性文字 | −1~1 多指标 | −1~1（41 bin + 置信度） | 无标准分数 | **可比较的数值分数** |
| 多空口径 | 操作建议+趋势 | **longVsShort** | 综合 impact | — | **多空净值** |

| 缺失值 | 留空 | **NA ≠ 0** | — | — | **需明确口径** |
| 主动推送 | 每日发文 | 数据流 | 数据流 | 邮件/移动端 | **盘前定期推送** |
| 可解释下钻 | 原文 | 分项指标 | 实体+事件标签 | **原文引用** | **建议补** |

## 四、本项目的定位与差距

### 4.1 定位

> **在期货研报这个垂直源上，做全市场多空观点的量化汇总，可纵向比较，主动送达。**

### 4.2 三个真实的差异化

| 差异化 | 相对谁 |
|---|---|
| **期货研报 × 全市场 × 多空量化** 的组合 | RavenPack/MarketPsych 以新闻为主、标的以股票为主；AlphaSense 覆盖研报但做检索不做量化 |
| **纵向可比的时间序列** | 曲合网等人工汇总只有横截面快照，看不出升温降温 |
| **主动推送到盘前** | 终端产品都是「用户来查」，只有异动才告警；本项目把多空结论作为**定期推送的主体内容** |

### 4.3 需要承认的差距

| 差距 | 对标 |
|---|---|
| 无置信度输出 —— 分不清「高置信度偏多」和「勉强偏多」 | RavenPack 的 41-bin 概率分布 |
| 热度与方向未分离 —— 3 家看多和 30 家看多可能同权 | MarketPsych 的 Buzz / Sentiment 双轨 |
| 分数无法下钻到原文 —— 交易员无法追问依据 | AlphaSense 的原文引用 |
| 未证明相对「数家数」的增量 | 华泰的中性化检验 |

## 五、可落地的改进项（按优先级，只列必要的）

**P0 —— 决定这个指标是否成立**

1. **观点级切分**：先按品种/周期切分再判多空，避免一篇里的对立观点被抹平（RavenPack 官方承认的局限）
2. **入库时点口径**：历史指标一律以研报进入系统的时间计算，杜绝未来函数（华泰研报的明确要求）
3. **中性化检验**：证明多空分相对「多少家看多 / 多少家看空」有增量，否则指标可被简单计数替代（华泰研报的检验结论）
4. **净得分 baseline**：先用 `(看多数 − 看空数) ÷ 总数 × 100` 跑出对照组，复杂模型必须跑赢它

**P1 —— 提升指标质量**

5. **Buzz / Sentiment 双轨**：拆出「研报覆盖家数」作为独立指标，并作为多空分的置信度权重（MarketPsych 做法）
6. **负面非对称加权**：对冲研报正面偏斜（华泰调整因子做法）
7. **缺失值口径**：无覆盖记 NA 不记 0；必须给值时给中性并显式标注为兜底（MarketPsych + Market-sentiment-index 做法）

**P2 —— 提升交付体验**

8. **三级下钻**：大盘多空分 → 分品种构成 → 支撑的研报原句（CNN F&G 的信息结构 + AlphaSense 的引用要求）
9. **多空矩阵视图**：机构 × 品种表格，对标曲合网人工版并叠加分数与环比（AlphaSense Generative Grid 形态）
10. **口径版本管理**：口径调整必须留版本并重算历史，否则纵向可比性失效
