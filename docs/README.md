# docs — 调研文档

## 调研口径

本项目要实现的**唯一功能**：

> 把从各家期货公司拿到的研报，判断成**看多 / 看空 / 中性**，汇总成「全市场当前偏多还是偏空」，且这个数按时间可比。

调研只围绕这一件事展开，**不做范围外的延伸**。

## 明确排除的方向

以下都跟「研报判多空」不是同一件事，本次调研已排除，避免过度设计：

- ❌ **量价类市场情绪指数**（CNN Fear & Greed、A 股情绪温度计类）—— 情绪来自行情，不来自研报
- ❌ **多 Agent 交易决策框架**（TradingAgents 等）—— 做的是买卖决策，不是研报观点判读
- ❌ **调查 / 持仓类情绪**（AAII、CFTC COT）—— 数据源完全不同
- ❌ **金融大模型训练与评测基准** —— 本项目不训模型底座

## 五条核心结论

1. **GitHub 上没有同形态项目。** 「研报 → 多空判断 → 全市场汇总」的完整实现搜不到。
2. **只有第一步有轮子。** 文本判多空可以复用 `finbert-tone`（训练语料就是分析师研报，标注就是句级三分类）和中文金融情感词典；**汇总与时间可比这两步基本要自研**，而这正是项目价值所在。
3. **需求已被人工满足，说明假设成立。** 期货资讯站每日人工出的「品种 × 期货公司 × 操作建议 × 趋势」汇总表就是人工版对手，它缺的时间序列、量化分数、大盘口径，正好是本项目的三个价值点。
4. **口径对标 MarketPsych 的 `longVsShort`**（买入引用净额减做空引用，−1~1），以及 IndexMundi 的净得分公式 `(看多数 − 看空数) ÷ 总数 × 100` —— 后者应作为 baseline，复杂模型必须跑赢它。
5. **四个必须规避的坑**：一篇研报观点不止一个（要先按品种/周期切分再判断）、分析师不轻易喊空（负面要非对称加权）、可能被"研报数量"解释掉（要做中性化检验）、用错时点会有未来函数（必须用入库时点）。
