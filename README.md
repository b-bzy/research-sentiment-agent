# 大盘市场情绪 Agent（期货研报情绪化打分）

> 国内某期货公司（总部）· AI 产品经理 · 2024.10 – 2025.03
> 把全市场期货研报的多空观点，量化成可追踪的大盘情绪指标

---

## 一、项目背景

期货交易员每天要面对数十家期货公司发布的研报。研报是判断市场共识的重要输入，但人工阅读存在三个问题：读不完、读得慢、读完之后拿不到一个可横向比较的量化结论。交易员真正需要的不是「今天某家怎么看」，而是**全市场当前偏多还是偏空、这个情绪相比上周是在升温还是降温**。

本项目基于交易员对大盘情绪指标的真实需求，搭建研报情绪化打分 Agent。

## 二、我的角色与职责

负责该 Agent 从需求分析到落地的产品工作。

### 1. 数据采集

- 实现**批量抓取多家期货公司研报**，覆盖主流机构的每日 / 每周研报
- 解决多来源、多格式研报的统一入库问题

### 2. 情绪打分模型

- 从研报正文中**提取多空观点关键词**
- **设定统计区间**（按日 / 周聚合），使单点研报的噪声不会主导指标
- 建立**评测指标与打分模型**，把定性的多空表述映射为可比较的数值分数

### 3. 主动推送

- 定期生成情绪指标结论并**主动推送**给交易员，而不是等人来查

## 三、关键设计取舍

- **为什么做指标而不是做摘要**：交易员不缺信息，缺的是可横向、纵向比较的量化口径。摘要只是把阅读量从 50 篇压到 50 段，量化打分才把它压成一个可追踪的数
- **为什么要设定统计区间**：单篇研报的观点方差极大，必须在区间上聚合才具备指示意义
- **为什么做主动推送**：情绪指标的价值在盘前，需要送到人面前，不能依赖用户主动打开

## 四、成果

- 交付研报情绪化打分 Agent，覆盖多家期货公司研报的批量抓取与统一处理
- 建立多空关键词提取 + 区间统计 + 打分模型的完整量化链路
- 实现情绪指标定期主动推送，为交易决策提供大盘情绪参考

### 跑一下 Demo

```bash
python3 run.py demo
```

**零第三方依赖**（不用 `pip install`），Python 3.10+ 约 0.2 秒跑完全链路：
27 篇样本研报 → 227 个观点块 → 大盘情绪分 65.5（偏多），
产出终端情绪日报、企业微信推送文案，以及一个自包含 HTML 看板（多空矩阵可悬停下钻到证据原句）。
181 个单元测试。详见 [docs/04-Demo说明.md](docs/04-Demo说明.md)。

代码就在仓库根目录：`run.py`（CLI）、`sentiment/`（7 个链路模块）、`tests/`、`data/inbox/`（样本研报）。
